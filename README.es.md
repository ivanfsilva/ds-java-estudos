Este repositorio contiene las soluciones a los ejercicios, desafíos y proyectos prácticos desarrollados durante las
capacitaciones de Java de la plataforma ⚡**DevSuperior**, impartidas por el Prof. Dr. Nélio Alves.

## 🚀 Cómo Ejecutar los Proyectos

1. Clona este repositorio:

```bash
git clone [https://github.com/ivanfsilva/devsuperior-java-estudos.git](https://github.com/ivanfsilva/devsuperior-java-estudos.git)
```

2. Navega hasta la carpeta del proyecto que deseas ejecutar.
3. Importa el proyecto en tu IDE preferido (IntelliJ IDEA, Eclipse, VS Code, etc.).
4. Navega hasta el paquete `application` y abre el archivo `Program.java`.
5. Ejecuta la clase `Program`.
6. Interactúa con el sistema a través de la consola de tu IDE, ingresando los datos según el ejemplo de entrada (
   recuerda utilizar el punto como separador decimal para valores numéricos).
