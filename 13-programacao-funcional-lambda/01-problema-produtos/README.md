# Exercício resolvido - filter, sorted, map, reduce

Fazer um programa para ler um conjunto de produtos a partir de um arquivo em formato .csv (suponha que exista pelo menos
um produto). Em seguida mostrar o preço médio dos produtos. Depois, mostrar os nomes, em ordem
decrescente, dos produtos que possuem preço inferior ao preço médio.

## Exemplo de entrada e saída

### Input file: Exemplo de arquivo de entrada (in.txt)
#### Para facilitar, copie o arquivo `in.txt` para a pasta `c:\temp\in.txt`.
```text
Tv,900.00
Mouse,50.00
Tablet,350.50
HD Case,80.90
Computer,850.00
Monitor,290.00
```
