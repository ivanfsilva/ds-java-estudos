## 🚀 How to Run the Projects

1. Clone this repository:

```bash
git clone [https://github.com/ivanfsilva/devsuperior-java-estudos.git](https://github.com/ivanfsilva/devsuperior-java-estudos.git)
```

2. Navigate to the project folder you wish to execute.
3. Import the project into your preferred IDE (IntelliJ IDEA, Eclipse, VS Code, etc.).
4. Navigate to the `application` package and open the `Program.java` file.
5. Run the `Program` class.
6. Interact with the application via your IDE console, entering data according to the input examples (remember to use a
   dot as the decimal separator for numeric values).
