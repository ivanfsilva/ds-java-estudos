# 📚 Estudos de Java & Orientação a Objetos Expert

Este repositório contém as soluções dos exercícios, desafios e projetos práticos desenvolvidos durante os treinamentos de Java da plataforma ⚡**DevSuperior**, ministrados pelo Prof. Dr. Nélio Alves.

O objetivo deste espaço é registrar minha evolução na linguagem Java, aplicando conceitos que vão desde a lógica de programação até o paradigma de Orientação a Objetos e estruturas de dados.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java (JDK 17+)
- **IDE:** IntelliJ IDEA

|  Cap.  | Módulo / Tópico                   | Conteúdo Principal                                                                    |     Status      |
| :----: | :-------------------------------- | :------------------------------------------------------------------------------------ | :-------------: |

## 🚀 Como Executar os Projetos

1. Clone este repositório:

```bash
git clone https://github.com/ivanfsilva/devsuperior-java-estudos.git
```

2. Navegue até a pasta do projeto que você deseja executar.
3. Importe o projeto para a sua IDE de preferência (Eclipse, IntelliJ IDEA, VS Code, etc.).
4. Navegue até o pacote `application` e abra o arquivo `Program.java`.
5. Execute a classe `Program`.
6. Interaja com o sistema através do console da sua IDE, inserindo os dados conforme o exemplo de entrada (lembre-se de
   utilizar ponto como separador decimal para os valores numéricos).
